✨ Getting started
  1. Pick a language by naming your file. Each tab is a file, and its extension sets the language — main.py → Python, index.html → HTML, app.js → JavaScript. Make a new file with +, rename it with the ✎ on the tab.
  2. Write your code in the editor on the left. As you type, grey suggestions appear — press Tab to accept one. (Try typing ! in an HTML file.)
  3. Run it with ▶ Run (or Ctrl/⌘ + Enter). The result shows on the right, and any error lines get marked in your code.
  4. Need to give input? Open 📥 to type standard input / command-line arguments before running.
🌐 Web pages (HTML / CSS / JS)

Make an HTML file plus CSS/JS files, and connect them with normal tags like <link href="styles.css"> / <script src="app.js"> (or the 🔗 button). The preview updates live as you type, and ⧉ pops it into a floating window.

🎨 Make it yours

The 🎨 panel changes the editor theme (presets, your own custom colours, light/dark) and keybindings (Default / Sublime / Vim). Drag the middle divider to resize panels, and use − / + to zoom each one.

🤖 Setting up AI (use your own key)
